# Stone Paper Scissors - Java

Stone Paper Scissors is a Java-based console game where the player competes against the computer. The computer randomly selects one of the three choices — Stone, Paper, or Scissors — and the program determines the winner based on the rules of the game.

The project demonstrates fundamental Java programming concepts including user input, conditional statements, random number generation, variables, loops, and basic program logic.

## About the Project

The main purpose of this project is to practice fundamental Java programming concepts by developing a simple interactive game.

The program allows the user to select Stone, Paper, or Scissors. The computer then generates a random choice, and the program compares both choices to determine whether the player wins, loses, or the game ends in a draw.

## How the Project Works

1. The program starts and asks the player to select Stone, Paper, or Scissors.
2. The player enters their choice.
3. The computer randomly generates its choice.
4. The program compares the player's choice with the computer's choice.
5. Based on the game rules, the result is determined.
6. The program displays the player's choice, computer's choice, and the result.
7. The game can continue for additional rounds if implemented.

## Game Rules

- Stone beats Scissors.
- Scissors beats Paper.
- Paper beats Stone.
- If both the player and computer select the same option, the game is a draw.

## How to Run

Clone the repository:

    git clone https://github.com/anushka-bhamare/stone-paper-scissors-java.git

Navigate to the project directory:

    cd stone-paper-scissors-java

Compile the Java program:

    javac src/com/result/Main.java

Run the program:

    java -cp src com.result.Main

Follow the instructions displayed in the console and enter your choice.
